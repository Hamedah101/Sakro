You already have the Backblaze code

This page is how you try it. You do not need to write the upload from scratch.

  1. Make a free Backblaze B2 account and create a bucket (a named folder in the cloud).
  2. Create an Application Key. Copy the Key ID and the Application Key (the key is shown only once).
  3. Paste those values below, plus your bucket name. Leave the storage address as-is unless Backblaze showed a different region.
  4. Click Save settings. Keys stay in a local .env file on this computer — never in git.
  5. Click Save a copy of traffic to Backblaze. A green or red message at the top of this page tells you if it worked.

The upload steps live in backblaze.py. The Save and Upload buttons are wired in app.py.

Monitor options

These choices stay on this computer. They do not change how packets are captured.

Default is https://s3.us-west-004.backblazeb2.com. Change the region if Backblaze shows a different one (example: eu-central-003).

Save writes these values to a local .env file. We never put real keys in the code.
